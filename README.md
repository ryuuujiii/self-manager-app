# 自分管理 — Phase 5

iPhoneのホーム画面から使う、費用ゼロを前提にした個人用Webアプリです。仕様書 v0.1 とUIモックを元に、Phase 5までの予定・ToDo・お金・仕事・生活機能を実装しています。

## 現在できること

- 5タブの画面構成（ホーム・予定・お金・仕事・生活）
- 予定の追加・編集・削除、月・週・日・30日一覧での表示
- 予定・ToDoの毎日／毎週／毎月の繰り返し
- ToDoの追加・編集・削除・完了管理（繰り返しは日ごとに完了）
- 予定・ToDo・固定費のアプリ内リマインダー一覧
- 今日の予定・ToDo・財布残高・今月の現金支出・習慣進捗のホーム集約、期限超過の表示
- 財布の現金残高、現金・現金以外の収支記録、現金だけのカレンダー（日別の入出金・明細・期間合計）と、現金以外も含む全記録一覧
- 毎月の給料日（1〜31日）と、土日・日本の祝日に重なる場合の「前の平日／後の平日」の設定。財布カレンダーは実際の給料日から次の実際の給料日の前日までを1期間として表示
- 財布と独立した固定費・サブスク管理（月額・年額、支払い済み、支払日のカレンダー表示）
- 複数の勤務先（名前・時給・給料日・場所・メモ）とシフトの登録・編集・削除
- シフトから勤務時間・勤務日数・給料見込みを計算し、予定カレンダーとホームの「次の仕事」に表示
- 予定・財布・仕事のカレンダーを日曜始まり・土曜終わりで統一
- 勤務先ごとの締め日の翌日から次の締め日までのシフトを集計し、給料日ごとの見込み額を表示
- 過去に登録したシフトから、勤務先・開始／終了時刻・休憩時間の組み合わせを選んで再利用
- 曜日別の習慣、日ごとのチェック履歴、週間達成数・連続達成数
- 大学・バイト・外出・旅行などの再利用できる持ち物チェックリスト
- 買い物リストと、価格・URL・画像URL・欲しい度を保存できる別のほしい物リスト
- ほしい物の購入時に家計簿への記録を選択（現金払いの場合だけ財布残高に反映）
- カテゴリ付きメモと、メモからToDo・予定への変換
- IndexedDBによる端末内保存
- JSONバックアップの書き出し・読み込み
- ホーム画面への追加、オフライン起動のためのPWA構成

給料見込みは時給とシフトから計算した目安で、財布残高には自動加算しません。

## 開発時の起動

Node.js 20以上を使い、以下を実行します。追加パッケージのインストールは不要です。

```powershell
npm run dev
```

`http://localhost:4173` を開きます。検証には `npm test` を使います。

公開用ファイルは `npm run build` で `dist/` に生成します。テストやビルドスクリプト、UIモックは `dist/` に入りません。`dist/` は生成物なのでGit管理しません。

GitHub Pagesへの移行中は、既存の公開元と公開URLを維持します。`.github/workflows/pages.yml` はPRでテストとビルドだけを行い、Pagesへの公開は `main` 上での `workflow_dispatch` による手動実行だけです。移行ブランチをpushしたりPRを作ったりしても公開されません。Pagesの公開元をGitHub Actionsへ切り替える前に、手動公開を実行しないでください。

`npm run prepare:pages` は従来の `publish/` リポジトリを使う手順として残しています。GitHub Actions公開を実機で確認した後は日常運用から外します。公開URLを維持するため、リポジトリ名を変更しません。端末内で入力した予定やToDoはリポジトリへ送信されません。

## iPhoneでの利用

HTTPSで静的ファイルを公開した後、iPhoneのSafariでURLを開き、共有メニューから「ホーム画面に追加」を選びます。公開先には無料の静的ホスティングを利用できます。個人データは公開先には送信されず、利用中の端末内に保存されます。

同じURLをSafariの通常タブとホーム画面アプリの両方で使った場合、保存領域が別になることがあります。日常利用はホーム画面アプリに統一し、設定画面から定期的にバックアップを書き出してください。ブラウザデータの削除や容量不足などでデータを失う可能性があります。

## 現在の設計上の制約

祝日判定には[内閣府の公表データ](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)を2027年まで同梱しています。2028年以降は暫定計算で、公式発表後に更新が必要です。会社や銀行固有の休業日は判定しません。給料日の設定を消すと、財布カレンダーは暦月表示に戻ります。給料日や休日の扱いを変更しても、収支記録の日付は変更しません。

SwiftUIアプリからWebアプリへ変更したため、ローカル通知、アプリ全体のFace IDロック、WidgetKitウィジェットはこのPhase 5にはありません。リマインダーはアプリを開いたときに確認する方式です。iPhoneへ指定時刻にバックグラウンド通知を届けるWeb Pushには配信元が必要です。

データは予定・お金・仕事の7ストアと、習慣・習慣履歴・持ち物・買い物・ほしい物・メモの6ストアに分けています。バックアップはv4で、旧形式（v1〜v3）も読み込めます。予定・ToDo・固定費・財布・シフトのカレンダー表示は保存用のコピーを作らず、元データから組み立てます。固定費の支払い済み操作は財布残高を変えません。勤務先の時給を変更すると、その勤務先の過去のシフトを含む給料見込みが再計算されます。

仕事の給料見込みは勤務先ごとに締め期間を切り替えて表示します。例えば20日締めなら9月21日〜10月20日を集計し、翌月5日払いなら11月5日の見込み額として表示します。支払月は締め日後の最初の給料日を自動選択するか、締めた月／翌月を明示できます。過去のシフト候補は保存済みシフトから生成し、テンプレートを別に保存しません。
